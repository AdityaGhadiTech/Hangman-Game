# 🎮 Hangman Game

A simple **Hangman game** built using **Python and Tkinter**.

## Features

* Random word selection
* Interactive letter buttons
* 6 lives
* Hangman display
* Win and game-over detection
* Play Again button

## Technologies

* Python
* Tkinter

## How to Run

```bash
python main.py
```
